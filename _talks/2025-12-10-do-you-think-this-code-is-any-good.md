title: "Do You Think This Code Is Any Good?"
speaker: "Sophie Chaveli"
date: 2025-12-10
time: "15:00–16:00"
room: "Mathematical Sciences Building, MB-204 (or via Teams)"
abstract: >
  Software now underpins almost every aspect of modern life, yet determining
  whether it is actually "good" remains a surprisingly hard problem. This
  talk explores how traditional code metrics can be supplemented using
  "brainwaves", or electroencephalography (EEG) data, to study how the human
  brain responds to software — with the aim of distinguishing good code from
  bad through measures of cognitive load and comprehension, combining
  machine learning, heuristic search, and applied statistics to analyse
  complex, real-world datasets. This interdisciplinary approach bridges
  software engineering, data science, and psychology, offering new ways to
  evaluate software quality by helping to harness programmer experience and
  "gut instinct".
tags: [data-science, software-engineering]
